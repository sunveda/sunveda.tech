## `rsvp-invitation-2026-09-12.html`

The `/rsvp/` invitation exactly as it stood for Sanya's 2nd birthday, captured
before the page became a post-event parking page. Open it in a browser — it is
self-contained, with no external assets besides the arrival-guide photo it
links to.

What it records:

| | |
|---|---|
| **Event** | Sanya's 2nd birthday — Saturday, 12 September 2026, 16:00–20:00 JST |
| **Venue** | UR Ojima 6-chome Danchi, Building 6 · 6 Chome-1-1 Ojima, Koto City, Tokyo 136-0072 |
| **Arrival** | Toei Shinjuku Line, Ojima Station (S15), Exit A2, about 5 minutes on foot — with the three-step photographed walking guide |
| **Timeline** | 16:00 Welcome & Free Play · 16:30 Kids' Games & Activities · 17:30 Family Photos · 18:00 Cake Cutting · 18:30 Dinner · 19:30 Return Gifts & Farewell · 20:00 Celebration Ends |
| **Links** | Building 6 map, Ojima Station map, parking map |
| **Languages** | English and Japanese, with the toggle added in PR #59 |

The RSVP and cancellation flows behind it lived in the Apps Script web app in
[sunveda/sanya-2nd-birthday-celebrations](https://github.com/sunveda/sanya-2nd-birthday-celebrations),
whose `CONTEXT.md` holds the decisions and deployment record. That app is now
closed.
