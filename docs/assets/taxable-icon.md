# Taxable icon

Asset: [taxable-icon-v1.png](../../taxable-icon-v1.png), a 512 × 512 PNG used in the homepage and app catalogue. The original was generated with the built-in image-generation tool; the website derivative is resized for delivery.

The mark combines a simple soroban-inspired silhouette with an abstract T, using SunVeda teal on warm off-white. The name stays in HTML for readability; the image contains no lettering.

## Generation prompt

Use case: logo-brand. Asset type: a production app icon for Taxable, a crypto tax calculator in development by SunVeda Technologies. Primary request: one original, simple, Japanese-inspired modern app icon. Create a bold geometric symbol combining the clarity of a tiny soroban (Japanese abacus) with a subtle abstract T. Two compact upright rails and a few generous rounded rectangular bead forms, assembled into one memorable balanced mark, not a detailed illustration. Flat minimalist Japanese graphic design, disciplined geometry, calm negative space, strong silhouette readable at 48px. Palette: deep teal matching SunVeda (#01696f) on a warm off-white solid square background. Composition: one centered mark occupying roughly 65 percent of the square, clean crisp edges, no border around the canvas. No text, no Japanese lettering, no coin symbols, no gradients, no texture, no mockup, no 3D, no shadow, no watermarks. Output one square icon only.
